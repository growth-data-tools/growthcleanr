# syngrowth

A synthetic set of 77,721 measurements from 2,697 subjects generated
using [Synthea](https://synthea.org/), with measurement errors for
testing with growthcleanr. Contains both pediatric and adult data.

## Usage

``` r
syngrowth
```

## Format

A data frame with six variables: `id`, `subjid`, `sex`, `agedays`,
`param`, and `measurement`

## Details

Example electronic health record (heightcm, weightkg) data.
