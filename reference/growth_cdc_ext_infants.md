# CDC Growth Reference Table

Part of default CDC-derived tables

## Details

Contains CDC LMS parameters and CSD values (median plus half the
distance to +/-2 SD) for weight, height, head circumference, and BMI, by
age in days and sex.

## growthfile_cdc_ext_infants.csv.gz

Used in function
