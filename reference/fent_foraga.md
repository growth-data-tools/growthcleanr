# Approximated Fenton Median Weights by Gestational Age

A table of approximated Fenton median weights by gestational age,
derived from printed Fenton (2025) charts. Maps sex and integer weight
(grams, rounded to nearest 10) to the gestational age in days at which
that weight is the median. These are approximations derived from the
charts, not values published by the Fenton authors. See
[`vignette("wrapper")`](https://growthcleanr.org/articles/wrapper.md),
"Gestational-age reference values".

## fent_foraga.csv.gz

Used in function
[`cleangrowth()`](https://growthcleanr.org/reference/cleangrowth.md) for
GA correction (Step 2b).
