# Evaluate single distinct value observations

Evaluate single distinct value observations

## Usage

``` r
eval_1d(subj_results, params)
```

## Arguments

- subj_results:

  data.table with result, meas_m, param, ageyears, internal_id columns
  for ONE subject – all params included

- params:

  List of limit parameters

## Value

Character vector of internal_ids to mark Exclude-A-Single
