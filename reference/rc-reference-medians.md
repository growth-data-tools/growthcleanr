# Recentering reference medians

Contains reference median z-scores (column rcmedian.sd) by age in days,
sex, and param, used for the default recentering in the child algorithm
(sd.recenter = NA). See vignette("recentering").

## rcfile-resmoothed.csv.gz

Used in function
[`cleangrowth()`](https://growthcleanr.org/reference/cleangrowth.md)
