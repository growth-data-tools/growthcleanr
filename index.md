An open-source R package that flags implausible values in longitudinal
pediatric and adult weight, height, and head circumference data.

**We are excited to announce the release of growthcleanr 3.0.0.**

## What does growthcleanr do?

- Infographic and fact sheet
  ([PDF](https://growthcleanr.org/growthcleanr-fact-sheet.pdf))
- Researcher overview

**Install.** From CRAN, in R: `install.packages("growthcleanr")`.

Source code is on
[GitHub](https://github.com/growth-data-tools/growthcleanr).

## About the project

fork it on [GitHub](https://github.com/growth-data-tools/growthcleanr).

**Related package.**
[cdcanthro](https://CRAN.R-project.org/package=cdcanthro) calculates WHO
and CDC z-scores and is commonly used alongside growthcleanr.
